# Feature: Create hello.sh executable script

## Description
Create a new executable Bash script `hello.sh` at the repository root that prints `Hello, World!` to stdout. This is the sole deliverable for the project — a greenfield addition with no modifications to existing files.

## Acceptance Criteria
- [ ] `hello.sh` exists at the repository root
- [ ] First line is exactly `#!/usr/bin/env bash`
- [ ] Script body is `printf 'Hello, World!\n'`
- [ ] File uses LF line endings and plain ASCII text
- [ ] Running `./hello.sh` outputs exactly `Hello, World!\n` to stdout
- [ ] Script exits with status `0`
- [ ] Script writes nothing to stderr
- [ ] File has the executable bit set on disk (`chmod +x`)
- [ ] Git tracks the file with mode `100755`
- [ ] No existing files are modified (README.md, .ralph/*, etc.)

## Files to Modify/Create
- `hello.sh` - Create new file with shebang and printf command; set executable permission and stage with `git add --chmod=+x hello.sh`

## Dependencies
- Requires: none
- Blocks: none (this is the only and final feature)

## Implementation Notes
1. Write the file with exactly two lines: the shebang and the printf statement.
2. Ensure executable bit is recorded in Git via `git add --chmod=+x hello.sh`.
3. Do **not** add tests, CI config, argument parsing, or any other files.

## Verification
```bash
test -x hello.sh
head -1 hello.sh | diff -u - <(printf '#!/usr/bin/env bash\n')
./hello.sh | diff -u - <(printf 'Hello, World!\n')
./hello.sh >/dev/null; test "$?" -eq 0
stderr="$(./hello.sh 2>&1 >/dev/null)"; test -z "$stderr"
git ls-files -s hello.sh | grep -Eq '^100755 '
```
