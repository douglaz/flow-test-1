# Feature: Fibonacci Function Implementation

## Description
Create a `fib.py` file at the repository root containing an iterative `fibonacci(n)` function that returns the nth Fibonacci number (0-indexed), with input validation for negative numbers, and a `__main__` block that prints the result of `fibonacci(10)`.

## Acceptance Criteria
- [ ] A file `fib.py` exists at the repository root
- [ ] `fibonacci(n)` uses an iterative approach (loop, not recursion) with O(n) time and O(1) space
- [ ] `fibonacci(0)` returns `0`
- [ ] `fibonacci(1)` returns `1`
- [ ] `fibonacci(10)` returns `55`
- [ ] `fibonacci(-1)` raises a `ValueError`
- [ ] Running `python fib.py` prints `55` to stdout
- [ ] No external dependencies — only Python standard library

## Files to Modify/Create
- `fib.py` - Create new file containing the `fibonacci(n)` function and `if __name__ == "__main__"` block

- Requires: none
