# Implementation Notes

## Decisions Made
- Used the classic iterative two-variable swap (`a, b = b, a + b`) which gives O(n) time and O(1) space as required.
- The loop runs `n` times starting from `(a, b) = (0, 1)`, so `a` holds `F(n)` after the loop — this naturally handles `n=0` (loop doesn't execute, returns 0) and `n=1` (one iteration, returns 1).
- Error message in `ValueError` is descriptive: `"n must be a non-negative integer"`.
