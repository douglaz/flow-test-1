# Feature: Prime Checker Script

## Description
Create a standalone Python script `is_prime.py` at the project root that implements a primality-checking function using trial division and prints results for integers 1 through 20 when executed directly. This is the sole deliverable for the project.

## Acceptance Criteria
- [ ] File `is_prime.py` exists at the project root
- [ ] Defines `is_prime(n: int) -> bool` that returns `True` for prime `n`, `False` otherwise
- [ ] Edge cases: `n <= 1` returns `False`; `n == 2` returns `True`; even `n > 2` returns `False`
- [ ] Uses trial division with only odd divisors from 3 to `math.isqrt(n)` (step 2)
- [ ] `if __name__ == "__main__"` block prints `is_prime(n)` for each `n` in 1–20, formatted as `{n}: {result}` (e.g., `1: False`, `2: True`)
- [ ] Runs without errors on Python 3.8+ with no external dependencies
- [ ] Output matches known primes in 1–20: 2, 3, 5, 7, 11, 13, 17, 19

## Files to Modify/Create
- `is_prime.py` — Create new file containing the `is_prime()` function and `__main__` block

## Dependencies
- Requires: none
- Blocks: none (this is the only feature in scope)
