# Feature: Word Count Script

## Description
Create a standalone Python script `wordcount.py` at the repository root that reads all text from stdin and prints the total word count to stdout. The script uses only the Python standard library, splitting on arbitrary whitespace via `str.split()` to correctly handle tabs, multiple spaces, and newlines.

## Acceptance Criteria
- [ ] A file `wordcount.py` exists at the repository root
- [ ] The file includes a `#!/usr/bin/env python3` shebang as the first line
- [ ] The script is executable (`chmod +x`)
- [ ] Running `echo "hello world" | python wordcount.py` prints `2`
- [ ] Empty input (`printf "" | python wordcount.py`) prints `0`
- [ ] Multiple lines are handled: `printf "one\ntwo three\n" | python wordcount.py` prints `3`
- [ ] Multiple/mixed whitespace is handled: `printf "  spaced   out  " | python wordcount.py` prints `2`
- [ ] Execution is wrapped in an `if __name__ == "__main__":` guard
- [ ] The counting logic uses `sys.stdin.read()` and `str.split()` (no arguments)

## Files to Modify/Create
- `wordcount.py` - Create new script: read stdin via `sys.stdin.read()`, split on whitespace with `str.split()`, print the length of the resulting list

## Dependencies
- Requires: none
- Blocks: none
