# Feature: Reverse String Script

## Description
Create a standalone Python script `reverse.py` at the project root that reads a single line from stdin, reverses it, and prints the result to stdout. The script uses only the Python standard library with minimal procedural code.

## Acceptance Criteria
- [ ] `reverse.py` exists at the project root
- [ ] `echo "hello" | python reverse.py` outputs `olleh`
- [ ] Handles empty input by printing an empty line
- [ ] Strips the trailing newline from input before reversing (does not reverse the newline character)
- [ ] Single character input returns that character unchanged
- [ ] Palindrome input returns the same string
- [ ] Input with spaces reverses the entire string including spaces (e.g., `"hello world"` → `"dlrow olleh"`)

## Files to Modify/Create
- `reverse.py` - Create new script that reads a line from stdin via `input()`, reverses it with `[::-1]` slice notation, and prints the result with `print()`

## Dependencies
- Requires: none
- Blocks: none
